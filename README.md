# ФУТБОЛ.TV

Сайт с реальными матчами, турнирными таблицами, составами, статистикой и прямыми
трансляциями из **VK Видео Live** и **OK Видео**.

Никаких заглушек: каждая строка в базе данных приходит из открытых источников
(openfootball, StatsBomb Open Data, live.vkvideo.ru, ok.ru, ESPN Site API) и имеет
поле `source`, по которому видно происхождение данных.

---

## Быстрый старт

```bash
npm install          # зависимости
npm run ingest       # собрать базу из реальных источников (нужен доступ к github.com)
npm run build        # собрать фронтенд
npm start            # запустить сервер на http://0.0.0.0:8080
```

Для разработки с горячей перезагрузкой — два терминала:

```bash
npm start            # API на :8080
npm run dev          # Vite на :5173, проксирует /api → 127.0.0.1:8080
```

Тесты:

```bash
npm test             # 20 юнит-тестов на node:test
npm run test:smoke   # монтирует настоящее приложение в jsdom и проходит все 9 маршрутов
                     # (нужен запущенный `npm start`)
```

## Откуда берутся данные

| Слой | Источник | Что даёт |
| --- | --- | --- |
| Календарь и результаты | [openfootball](https://github.com/openfootball) (`football.json`, `europe`) | ~125 000 реальных матчей, 85 турниров, 385 сезонов, даты, время, тур, счёт и счёт перерыва |
| Составы, события, статистика | [StatsBomb Open Data](https://github.com/statsbomb/open-data) | протоколы матчей: стартовый состав, замены, голы, карточки, xG, владение, удары, пасы, обводки, отборы |
| Прямые трансляции | [live.vkvideo.ru](https://live.vkvideo.ru), категория «Футбол» | реальные эфиры с названием, каналом, числом зрителей и ссылкой |
| Прямые эфиры | [ok.ru/video/live](https://ok.ru/video/live) | круглосуточные эфиры телеканалов в OK Видео |
| Живой счёт | ESPN Site API (`site.api.espn.com`, без ключа) | текущий счёт, минута, статус, стадион, посещаемость |
| Эмблемы клубов | [sportlogos/football.db.logos](https://github.com/sportlogos/football.db.logos) | 334 настоящих PNG-эмблемы; 212 подошли клубам из базы, лежат в `web/public/crests/` |

Турнирные таблицы **не скачиваются**, а считаются по реально сыгранным матчам
(`ingest/standings.js`).

### Два слоя данных — и почему вкладки матча бывают пустыми

| Слой | Матчей | Что есть |
| --- | --- | --- |
| openfootball | 114 386 | дата, время, тур, счёт, счёт перерыва |
| ESPN live | 9 лиг | + текущий счёт и минута, поминутные события (голы, карточки, замены), командная статистика: владение, удары, удары в створ, угловые, фолы, голевые передачи |
| StatsBomb | 680 | + стартовые составы с номерами, xG, пасы, обводки, отборы, сейвы |

ESPN покрывает `rus.1, eng.1, eng.2, esp.1, ita.1, ger.1, fra.1, uefa.champions,
uefa.europa`. События и статистика берутся из `details` и `statistics` скорборда,
поэтому они появляются у каждого матча этих лиг, а не только у турниров StatsBomb.
Авторов голов видно прямо в шапке матча; бомбардиры live-слоя пересчитываются
из событий каждый проход (`rebuildEspnScorers`), поэтому повторный инжест не
удваивает голы.

Голевая передача **конкретного** гола в скорборде ESPN отсутствует — там есть
только общее число голевых передач команды (`goalAssists`), оно и показывается
в статистике матча.

Протокол (составы / события / статистика) есть **только у 680 матчей StatsBomb** —
это реальные данные, но они покрывают конкретные турниры: ЧМ-2022, Евро-2020 и 2024,
Копа Америка-2024 и отдельные сезоны АПЛ, Ла Лиги, Бундеслиги, Лиги 1, Лиги чемпионов.
У календарного матча из openfootball протокола нет физически, и вкладки честно это
говорят, предлагая переход к матчам с протоколом.

Чтобы такие матчи не терялись: на главной есть раздел **«Матчи с протоколом»**,
в списке матчей — фильтр **«С протоколом»** (`GET /api/matches?withDepth=1`),
а в строке матча — значок `протокол`.

### Эмблемы

Соответствие «файл эмблемы → команда» находится автоматически (`ingest/crests.js`):
нормализованное имя файла сравнивается с тремя вариантами имени команды — id,
официальным названием и русским названием транслитом, — а страна клуба берётся из
турниров, в которых он играет. Именно страна не даёт эмблеме «Арсенала» из Саранди
улечься на лондонский «Арсенал». Там, где имя файла и название клуба расходятся
(`paris.png` — это ПСЖ), стоит явное соответствие.

Сейчас эмблемы есть у **274 клубов** (212 сопоставленных файлов; openfootball хранит
один клуб под разными ключами — `real` и `real-madrid-esp`, — поэтому эмблема
раздаётся обоим вариантам). У остальных — аккуратная плашка с буквами в цветах клуба:
в источнике просто нет их логотипа (например, ЦСКА, «Рейнджерс», «Бирмингем»).

### Автообновление

Расписание — это не зашитый в код список: в базе 115 066 матчей из openfootball,
а идущие игры поверх обновляет ESPN.

* **Сервер** (`server/refresh.js`) каждые 10 минут (`REFRESH_MINUTES=…`) заново
  обходит VK Видео Live, OK Видео и ESPN и перезаписывает снимки в `data/snapshots/`.
* **Браузер** подтягивает данные сам: главная и трансляции — раз в 60 с, карточка
  матча — раз в 30 с, список матчей — раз в 2 мин, шапка — раз в минуту.
* Кнопка **⟳ Обновить** в шапке дёргает `POST /api/refresh` и запускает проход
  немедленно; состояние видно в `GET /api/meta → refresh`.
* Если исходящего интернета нет, каждый проход берёт последний реальный снимок и
  помечает режим как `snapshot` — молча устаревших данных не показываем.

### Как трансляция привязывается к матчу

`lib/matcher.js` транслитерирует название эфира («ОРЕНБУРГ - АКРОН») и сравнивает
токены с названиями команд из базы (`FK Orenburg` / `Оренбург`). Связь создаётся,
если найдены обе команды, либо одна команда плюс ключевое слово турнира
(РПЛ, АПЛ, Лига чемпионов…). Всё, что не сматчилось, остаётся в общем списке эфиров.

## Инжест

```bash
npm run ingest                          # всё целиком
npm run ingest -- --only=openfootball   # только календарь и результаты
npm run ingest -- --only=statsbomb      # только составы/события/статистика
npm run ingest -- --only=streams        # только трансляции
npm run ingest -- --only=espn           # только живой слой ESPN
npm run ingest -- --no-live             # не ходить в сеть за эфирами (брать снимки)
npm run ingest -- --no-events           # пропустить события StatsBomb (быстрее)
```

Шаги:

1. Клонирует `openfootball/football.json`, `openfootball/europe` и
   `statsbomb/open-data` (blob-less + sparse checkout) в `.cache/`.
2. Разбирает JSON и текстовые форматы openfootball → `matches`, `teams`,
   `competitions`, `seasons`.
3. Разбирает StatsBomb → `lineups`, `match_events`, `match_stats`, `scorers`.
4. Считает турнирные таблицы.
5. Обновляет трансляции и связывает их с матчами в окне −6 ч … +48 ч.
6. Обновляет живой слой ESPN (если есть исходящий интернет).

### Снимки трансляций

Если у сервера нет исходящего интернета, трансляции берутся из
`data/snapshots/*.json`. Это **реальные** снимки с временем захвата в поле
`captured_at`, а не выдуманные данные. В интерфейсе время снимка показывается явно.

## Схема базы (`data/football.db`, SQLite)

`competitions`, `seasons`, `teams`, `team_aliases`, `players`, `matches`,
`lineups`, `match_events`, `match_stats`, `standings`, `scorers`, `streams`,
`match_streams`, `meta`.

Схема объявлена в `server/db.js`. База не хранится в git — она собирается
командой `npm run ingest`.

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| GET | `/api/meta` | состояние базы и источники |
| GET | `/api/overview` | витрина: featured-матч, live, ближайшие матчи, эфиры, бомбардиры |
| GET | `/api/matches` | матчи с фильтрами `status`, `competition`, `season`, `team`, `from`, `to`, `day`, `withStreams`, `order`, `limit` |
| GET | `/api/matches/:id` | матч: события, составы, статистика, трансляции, личные встречи |
| GET | `/api/competitions` | список турниров |
| GET | `/api/competitions/:id` | сезоны, таблица, бомбардиры, туры, матчи |
| GET | `/api/teams/:id` | команда, ближайшие матчи, результаты, игроки |
| GET | `/api/streams` | трансляции с привязанными матчами (`platform`, `matched`) |
| GET | `/api/health` | проверка доступности |
| POST | `/api/refresh` | немедленно пересобрать трансляции и живой счёт |

Статические эмблемы отдаются из `dist/crests/…` (после `npm run build`).

## Структура

```
ingest/          инжест из внешних источников
  openfootball.js  календарь и результаты (JSON + текстовый формат)
  statsbomb.js     составы, события, статистика
  streams.js       VK Видео Live / OK Видео + снимки
  espn.js          живой счёт
  standings.js     турнирные таблицы
  competitions.js  справочник турниров и таймзон
  teams.js         русские названия клубов и сборных
server/          Express + node:sqlite (API и раздача статики)
lib/             общие утилиты: транслитерация, время, матчинг трансляций
web/             фронтенд: Vite + React
data/snapshots/  реальные снимки трансляций
tests/           node:test
```

Требования: Node.js 22.5+ (используется встроенный `node:sqlite`).

## Известные ограничения

* **Встраивание плеера VK.** `live.vkvideo.ru` отдаёт плеер только по ссылке
  `video_ext.php` с параметром `hash`, который без токена VK недоступен, поэтому
  эфир открывается на площадке вещателя в новой вкладке. Поле `embed_url` в
  таблице `streams` зарезервировано: если появится hash или DevAPI-токен,
  плеер встроится без изменений в интерфейсе.
* **Живой слой требует интернета.** Без исходящего соединения сайт показывает
  данные из базы; статус «live» и минута считаются от реального времени начала
  матча, устаревшие live-статусы автоматически переводятся в «завершён».
* **РПЛ 2026/27** отсутствует в openfootball, поэтому текущий сезон РПЛ берётся
  из ESPN: шаг `npm run ingest:live` скачивает скорборд и сохраняет снимок в
  `data/snapshots/espn-<лига>-<дата>.json`. Без интернета используется последний
  такой снимок.
* **Снимки в репозитории.** `data/snapshots/*.json` захвачены 6 сентября 2026 года
  веб-инструментами агента, потому что из песочницы, где собирался проект, нет
  прямого исходящего HTTPS (доступны только npm, PyPI и github.com). Это реальные
  данные с реальным временем захвата, а не заглушки; на сервере с интернетом
  `npm run ingest` перезапишет их свежими.
